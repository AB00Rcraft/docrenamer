# Обратная связь об именах

Сюда складывается свод отчётов, присланных пользователями кнопкой «Улучшение»
в программе. Файлы создаёт `tools/collect_feedback.py`:

```bash
python tools/collect_feedback.py --state all
```

- `SUMMARY.md` — что чинить в первую очередь, по-русски;
- `aggregated.json` — тот же свод в машинном виде.

Свод коммитится в репозиторий намеренно: следующая сессия работы над именами
видит накопленные замечания, даже если у неё нет доступа к GitHub. Ни имён
файлов, ни фамилий, ни текста документов в отчётах нет — только статистика.

# Ренеймер документов

«Ренеймер документов» (DocRenamer Offline) анализирует файлы в выбранной папке
и предлагает для них осмысленные
имена: по типу документа, дате, номеру дела или договора, ключевым лицам и
организациям. Переименование выполняется только по вашей команде и только
внутри той же папки.

**Работает полностью без Интернета.** Ничего не отправляется наружу.

---

## Что скачивать

Нужен **один** файл, а не все три:

| Файл | Кому | Что делать |
|---|---|---|
| `DocRenamer-Setup.exe` | большинству | запустить — установится сам |
| `DocRenamer.exe` | если ставить не хотите | положить в отдельную папку и запустить оттуда |
| `DocRenamer-portable.zip` | если добавите OCR и модель | распаковать целиком в отдельную папку |

Программа кладёт журналы и данные для отмены **рядом с собой**, поэтому не
запускайте её прямо из «Загрузок» — положите в свою папку. После установщика
об этом думать не нужно.

Распознавание сканов и локальная модель, если они понадобятся, кладутся
**в ту же папку**, где лежит программа: `runtime\tesseract\`, `models\`.
Подробности — в `runtime\README.md`. Проверить, что всё подключилось, —
кнопка «Самопроверка».

## Где взять программу

**Готовый `DocRenamer.exe`.** Загрузите репозиторий на GitHub и запустите
сборку: вкладка **Actions** → «Сборка для Windows» → **Run workflow**. Через
несколько минут в разделе артефактов появятся два файла:

- `DocRenamer-onefile` — один `DocRenamer.exe`, ничего устанавливать не нужно;
- `DocRenamer-portable` — раскладка по разделу 4 ТЗ, сюда кладутся OCR и модель.

Если создать тег вида `v1.0.0`, те же файлы автоматически прикрепятся к релизу
вместе с контрольными суммами.

**Своя сборка на Windows.** Нужен Python 3.12 x64:

```bat
build_windows.bat onefile
```

Скрипт создаст окружение, установит зафиксированные зависимости, прогонит
тесты и аудит офлайн-режима и соберёт `dist\DocRenamer\DocRenamer.exe`
и `dist\onefile\DocRenamer.exe`.

Один файл удобнее переносить, каталог запускается быстрее и именно в него
кладутся OCR и локальная модель.

## Быстрый запуск

1. Запустите `DocRenamer.exe`.
2. Выберите папку.
3. Нажмите `Сканировать`.
4. Проверьте предложения.
5. Нажмите `Переименовать`.

Первый запуск лучше делать на копии папки.

---

## Обновления

В окне есть кнопка «Обновления»: программа сообщит, если вышла новая версия,
и по вашему согласию скачает и установит её, после чего запустится заново.

Само обновление выполняет **отдельная программа** `DocRenamerUpdate.exe`.
Это сделано намеренно: приложение, которое читает ваши документы, не содержит
сетевого кода вообще — это проверяется аудитом при каждой сборке. Программа
обновления, наоборот, знает про сеть, но никогда не открывает ваши файлы: она
скачивает установщик, сверяет его контрольную сумму и запускает.

Ничего не происходит само по себе: проверка запускается только по нажатию
кнопки. Автоматическую проверку при запуске можно включить в `config.json`
(`update.check_on_start`), по умолчанию она выключена.

## Гарантии

- Интернет не нужен;
- данные не отправляются наружу — ни при каких настройках;
- файлы не пересохраняются — меняется только имя;
- по умолчанию работает предпросмотр, без изменений на диске;
- ведётся журнал каждого запуска;
- есть отмена последней операции;
- контрольная сумма SHA-256 проверяется до и после переименования;
- существующий файл никогда не перезаписывается;
- ничего не удаляется и не перемещается в другие папки.

## Что распознаётся

| Категория | Форматы |
|---|---|
| Документы | PDF, DOCX, XLSX, XLSM, PPTX, RTF, TXT, MD, CSV, LOG |
| Разметка и данные | HTML, XML, JSON, GPX, KML, KMZ |
| Старый Office | DOC, XLS, PPT — частично: свойства документа |
| Изображения | JPG, PNG, TIFF, HEIC, HEIF, AVIF, WEBP, BMP, GIF, DNG и RAW |
| Видео | MP4, MOV, M4V, AVI, MKV, WEBM, 3GP, MTS, M2TS |
| Аудио | MP3, M4A, AAC, WAV, FLAC, OGG, OPUS, WMA, AIFF, AMR |
| Почта | EML, MSG |
| Архивы | ZIP, 7Z, RAR, TAR, GZ — только список содержимого, без распаковки |

Без внешних компонентов программа всё равно читает документы, определяет дату
съёмки фотографий и видео и работает с почтой и архивами: EXIF читается
средствами Pillow, а контейнеры MP4/MOV разбираются напрямую. Отдельно
устанавливаются только распознавание сканов (Tesseract) и локальная модель.

Русский язык — основной режим работы. Понимаются кодировки Windows-1251,
KOI8-R, CP866, ISO-8859-5, UTF-8 и UTF-16, русские даты («18 августа 2026 года»)
и ФИО в разных формах записи.

## Какие документы программа узнаёт

В справочнике 103 вида документов, и он расширяется правкой одного файла —
`config/document_types.json`, перезапуск не нужен.

| Область | Примеры |
|---|---|
| Судебные акты | решение и определение суда, апелляционное и кассационное определение, приговор, судебный приказ, исполнительный лист, протоколы допроса, осмотра, обыска |
| Исполнительное производство | постановления пристава, следователя, дознавателя |
| Договоры | купли-продажи, займа, аренды, подряда, оказания услуг, поставки, дарения, цессии, залога, кредитный, трудовой |
| Деловой оборот | коммерческое предложение, соглашение о неразглашении (NDA), письмо о намерениях (LOI), техническое задание, гарантийное письмо, оферта, спецификация, смета |
| Корпоративные | устав, протокол общего собрания, решение единственного участника, выписка из ЕГРЮЛ и ЕГРН |
| Бухгалтерия | счёт, счёт-фактура, акт выполненных работ, акт приёма-передачи, акт сверки, платёжное поручение, товарная накладная, банковская выписка |
| Аналитика и проекты | справка установочная и ситуационная, аналитическая записка, резюме проекта, бизнес-план, финансовая модель, дорожная карта, меморандум, протокол встречи |
| Прочее | доверенность, расписка, страховой полис, ПТС, технический и кадастровый паспорт, должностная инструкция |

Вид документа всегда идёт первым словом имени. Если определить его не удалось,
имя начинается с нейтрального обозначения по формату файла — «Документ»,
«Таблица», «Презентация», «Фото».

## Хорошие имена не ломаются

Если файл уже назван по-человечески, программа не переписывает имя. Максимум —
добавляет дату в начале по единому образцу, и только если её в имени ещё нет:

```text
Постановление по делу Иванова.pdf
  → Постановление по делу Иванова_27.07.2026.pdf

Договор займа №17 от 18 августа 2026 года.docx
  → не трогаем: имя осмысленное и дата в нём уже есть

scan0007.pdf
  → Договор_Петров_ООО_Альфа_17_18.08.2026.pdf
```

Пробелы, «№», кавычки «» и регистр букв сохраняются как есть. Техническими
считаются имена вида `IMG_0032`, `scan0007`, `20260818_142203`,
`Новый документ` — их программа заменяет полностью.

Отключается настройкой `naming.preserve_good_names`.

## Тома и части одного документа

Файлы, отличающиеся только номером, распознаются как части одного документа —
номер части сохраняется, и они не сливаются в одно имя:

```text
scan_1.pdf, scan_2.pdf, scan_3.pdf
  → Постановление_СПИ_Иванов_1_из_3_27.07.2026.pdf  (и 2_из_3, 3_из_3)

Опись том 1.pdf, Опись том 2.pdf
  → слово «том» из исходного имени сохраняется
```

Если во втором томе нет шапки с датой или номером дела, они берутся из
соседнего тома — в журнале и manifest прямо указано, из какого файла.

## Как выглядит результат

```text
IMG_0032.pdf
  → Постановление_СПИ_Иванов_652102_26_77028-ИП_27.07.2026.pdf

scan0007.docx
  → Договор_Петров_ООО_Альфа_17_18.08.2026.docx

IMG_7834.HEIC
  → Фото_iPhone_16_Pro_03.08.2026_18.42.17.heic
```

Разделитель частей имени — одинарное подчёркивание, и только он. Дефис
остаётся лишь там, где он часть самого значения: «пристав-исполнитель»,
«Бета-Инвест», «652102_26_77028-ИП».

Первым идёт вид документа, дата — в конце: так файлы удобно сортировать по
имени, однотипные документы оказываются рядом. Хронологический порядок
включается настройками `naming.order: "date-first"` и `date_format: "YYYY-MM-DD"`.

Если уверенности не хватает, файл остаётся как есть, а в списке появляется
пометка `НЕ БУДЕТ ПЕРЕИМЕНОВАН АВТОМАТИЧЕСКИ`. Лучше оставить имя прежним, чем
дать неверное.

## Командная строка

```bat
DocRenamer.exe                              графический интерфейс
DocRenamer.exe "D:\Документы"               предпросмотр
DocRenamer.exe "D:\Документы" --apply       переименовать
DocRenamer.exe --here --recursive           текущая папка с подпапками
DocRenamer.exe "D:\Документы" --forensic    только отчёты, без изменений
DocRenamer.exe --undo ".\manifests\rename_manifest_2026-08-18_142203.json"
DocRenamer.exe --no-ai --no-ocr             без модели и без распознавания
```

По умолчанию выполняется предпросмотр.

---

## Отмена

Каждое применение записывает manifest в папку `manifests\`. Отменить операцию
можно кнопкой `Отменить последнее` или командой `--undo` с путём к manifest.
Перед откатом проверяется, что файл не изменился и старое имя свободно.

## Где что лежит

```text
DocRenamer\
├── DocRenamer.exe
├── config\        настройки и словарь типов документов
├── runtime\       локальные программы: OCR, ExifTool, ffprobe, 7-Zip, llama.cpp
├── models\        локальная языковая модель (.gguf)
├── logs\          журналы запусков
└── manifests\     файлы для отмены
```

Папку можно переносить целиком, в том числе на флешке: привязки к букве диска нет.

## Если чего-то не хватает

Программа никогда не скачивает недостающие компоненты. Вместо этого она честно
сообщает об ограничении:

| Сообщение | Что означает |
|---|---|
| `LOCAL_MODEL_NOT_FOUND` | нет файла модели в `models\` — работают только правила |
| `OCR_ENGINE_NOT_FOUND` | нет Tesseract в `runtime\tesseract\` — сканы не распознаются |
| `DATE_SOURCE_FILE_PROPERTY` | дата взята из свойств файла, а не из текста документа |
| `SKIPPED_LOW_CONFIDENCE` | имя предложено, но уверенности мало — решение за вами |
| `SOURCE_CHANGED_AFTER_PREVIEW` | файл изменился после предпросмотра, пропущен |
| `ENCODING_UNCERTAIN` | не удалось надёжно определить кодировку текста |

## Настройки

Кнопка `⚙ Настройки` или файл `config\config.json`. Основное:

- `naming.confidence_threshold` — порог автоматического переименования (0.88);
- `naming.max_filename_length` — предельная длина имени (160);
- `ocr.languages` — языки распознавания (`rus`, `eng`);
- `ai.enabled`, `ocr.enabled` — использовать ли модель и распознавание;
- `media.include_gps_coordinates` — добавлять ли координаты в имена фотографий.

## Для разработчиков

```bash
python -m venv .venv && .venv/bin/pip install -e ".[dev]" -r requirements-dev.txt
pytest -q                                             # все тесты
pytest -m safety                                      # инварианты безопасности
python -m docrenamer.security.offline_guard --audit src   # аудит офлайн-режима
ruff check src tests
```

Техническое задание — `documentation.md`, архитектура — `ARCHITECTURE.md`,
правила для агентов — `AGENTS.md`.

## 1. Что делает программа

Программа читает файлы в выбранной папке и предлагает для каждого осмысленное
имя: вид документа, участники, номер дела или договора, дата. Переименование
выполняется только по вашей команде и только внутри той же папки.

Что она берёт из файла:

| Источник | Что оттуда извлекается |
|---|---|
| Текст документа | вид документа, дата, номера, ФИО, организации, предмет |
| Свойства файла (метаданные) | автор, дата создания, камера, координаты, длительность |
| Распознавание сканов (OCR) | текст со снимков и сканов, если распознавание установлено |
| Имя файла и соседей | номера томов и страниц, осмысленное имя, данное человеком |
| Локальная модель | разрешение неоднозначностей, если правил не хватило |

Всё происходит на вашем компьютере. Интернет не нужен, документы наружу не
уходят ни при каких настройках.

## 2. Чего программа не делает никогда

Это не пожелания, а свойства устройства программы — они проверяются
автоматическими тестами при каждой сборке.

- **Не меняет содержимое файла.** Переименование меняет только запись в
  каталоге: размер, содержимое и время изменения остаются прежними, и
  программа сверяет контрольную сумму SHA-256 до и после операции.
- **Не перезаписывает существующие файлы.** Если имя занято, к новому имени
  добавляется номер: `Договор_18.08.2026__02.pdf`.
- **Ничего не удаляет.**
- **Не перемещает файлы в другие папки.** Только переименование на месте.
- **Не выходит в сеть.** В программе, которая читает документы, сетевого кода
  нет вовсе. Обновления скачивает отдельная программа, документы она не
  открывает.
- **Ничего не скачивает сама** — ни модель, ни распознавание. Если чего-то
  нет, она честно говорит об этом и работает без него.
- **Не выполняет макросы и сценарии** из документов.
- **По умолчанию ничего не меняет:** сначала предпросмотр, изменения — только
  по нажатию «Переименовать».

Единственная операция, которая меняет сам файл, — «Очистить метаданные», и
она запускается отдельной командой, по умолчанию работает с копиями и
записывает отчёт. См. [раздел 11](#11-очистка-метаданных).

## 3. Установка и первый запуск

### Что скачивать

Нужен **один** файл, а не все:

| Файл | Кому | Что делать |
|---|---|---|
| `DocRenamer-Setup.exe` | большинству | запустить, программа установится сама |
| `DocRenamer.exe` | тем, кто не хочет ставить | положить в отдельную папку и запустить оттуда |
| `DocRenamer-portable.zip` | тем, кто добавит OCR и модель | распаковать целиком в отдельную папку |

### Куда положить

Программа кладёт журналы и данные для отмены **рядом с собой**. Поэтому не
запускайте её прямо из «Загрузок»: заведите отдельную папку, например
`C:\DocRenamer`. После установщика об этом думать не нужно.

Папку можно переносить целиком, в том числе на флешке, — привязки к букве
диска нет.

### Первый запуск

Первый раз запустите программу **на копии** рабочей папки. Не потому, что
что-то может пропасть — отмена есть всегда, — а чтобы спокойно посмотреть,
какие имена она предлагает, и настроить порог уверенности под свои документы.

## 4. Готовность комплекта

В заголовке окна справа стоит значок готовности. Наведите на него — покажется,
что найдено, а что нет. Кнопка **«Ещё» → «Самопроверка»** проверяет всё
заново и пишет подробности в журнал.

| Состояние | Что это значит |
|---|---|
| Всё на месте | распознавание сканов и локальная модель найдены |
| Работает без дополнений | документы, фото, видео и почта разбираются, сканы — нет |
| Чего-то не хватает | подробности в подсказке и в журнале |

**Что программа умеет без всяких дополнений:** читать PDF с текстовым слоем,
DOCX, XLSX, PPTX, RTF, TXT, HTML, XML, JSON, почту EML и MSG, список
содержимого архивов, дату съёмки фотографий (EXIF читается своими силами) и
метаданные MP4/MOV.

**Что добавляется отдельно:**

| Компонент | Куда класть | Что даёт |
|---|---|---|
| Tesseract | `runtime\tesseract\` | распознавание сканов и снимков документов |
| Модель GGUF | `models\document-model.gguf` | разрешение неоднозначностей в сложных документах |
| ExifTool | `runtime\exiftool\` | полные метаданные фото, включая RAW и XMP |
| ffprobe | `runtime\ffmpeg\` | метаданные AVI, MKV, WEBM, кодеки и разрешение |
| 7-Zip | `runtime\7zip\` | список содержимого 7Z и RAR |

Подробности — в `runtime\README.md`. Программа никогда не скачивает эти
компоненты сама.

## 5. Окно программы

```text
┌────────────────────────────────────────────────────────────────────────────┐
│  Ренеймер документов                    ✓ готово    ● ТОЛЬКО ЛОКАЛЬНО      │
│ ────────────────────────────────────────────────────────────────────────── │  ← ход работы
│  Папка  [ D:\Дело Петрова\Том 1              ]  [ Выбрать ] [ Сбросить ]  │
│  ○ Анализ  ● Предпросмотр  ○ Применить   ☑ Включая подпапки  ☐ Только новые│
├──────────────────────────────────────────┬─────────────────────────────────┤
│ ЧТО БУДЕТ ПЕРЕИМЕНОВАНО      [Снять все] │ ПРЕДПРОСМОТР  [Перейти к файлу] │
│ ┌ Файл или папка ─┬ ✓ ┬ Предлагаемое имя │  ┌───────────────────────────┐   │
│ │ договор.docx    │ ☑ │ Договор_ООО…     │  │  первая страница скана    │   │
│ │ 📁 Сканы        │ ☑ │ Иск_Шахманова    │  │  или начало документа     │   │
│ │   скан 1.jpg    │ ☑ │ Иск_…_стр_1      │  └───────────────────────────┘   │
│ │   скан 2.jpg    │ ☑ │ Иск_…_стр_2      │ СВЕДЕНИЯ О ФАЙЛЕ                │
│ │ desktop.ini     │ ☐ │ служебный файл   │  Вид: Исковое заявление (текст) │
│ └─────────────────┴───┴──────────────────│  Уверенность: 94%  ...          │
│                                          │ ЖУРНАЛ РАБОТЫ                   │
│                                          │  [16:22:05] Разбор: 38 из 184   │
├──────────────────────────────────────────┴─────────────────────────────────┤
│ [Сканировать] [Предпросмотр] [Переименовать] [Отменить] [Стоп]             │
│ [Объединить] [Изменить имя]                                        [ Ещё ] │
│ Разбор: 38 из 184, осталось 146                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

Что где:

- **Строка папки** — путь можно вписать руками или вставить из буфера, а можно
  выбрать кнопкой «Выбрать» ([раздел 6.1](#61-выбор-папки)).
- **«Сбросить»** — начать сначала: список, предпросмотр и журнал очищаются, а
  рабочей папкой снова становится домашняя. Во время работы кнопка попросит
  сперва остановить её кнопкой «Стоп».
- **Режимы** — «Анализ» (только разбор), «Предпросмотр» (план без изменений),
  «Применить». По умолчанию предпросмотр.
- **Флажки** — «Включая подпапки» и «Только новые»
  ([раздел 12](#12-большие-папки-и-повторные-запуски)).
- **Список** — дерево: сначала файлы корня, ниже папка и под ней её
  содержимое. Галочка на папке распространяется на всё её содержимое.
- **Предпросмотр** — снимок и первая страница PDF показываются картинкой,
  документ — началом текста. По нему сразу видно, то ли это, что написано в
  имени. Кнопка **«Перейти к файлу»** над предпросмотром открывает папку с
  этим файлом в проводнике: в Windows файл в ней сразу выделен. Работает и
  сразу после сканирования, до предпросмотра.
- **Сведения о файле** — где лежит, что распознано и на каком основании,
  участники, номер дела, уверенность, размер, время изменения, контрольная
  сумма.
- **Журнал работы** — то же, что пишется в файл журнала.
- **Ряд кнопок** — действия над файлами: «Сканировать», «Предпросмотр»,
  «Переименовать», «Отменить», «Стоп», «Объединить», «Изменить имя»; служебное («Самопроверка»,
  «Журнал работы», «Отчёт об именах», «Настройки», «Проверить обновления») —
  под кнопкой **«Ещё»**.
- **Полоса хода работы** — тонкая линия под заголовком, расходится от
  середины. Внизу — то же словами: «Разбор: 1240 из 4500, осталось 3260».
- **● ТОЛЬКО ЛОКАЛЬНО** — напоминание, что документы никуда не отправляются.

### Подсказки

У кнопок и флажков есть всплывающие подсказки. Они появляются, только если
указатель задержался на элементе управления **примерно на полсекунды** и по
нему не нажали, держатся несколько секунд и исчезают сами. Нажатие убирает
подсказку сразу. Сделано так намеренно: подсказка, выскакивающая мгновенно,
загораживает соседние кнопки как раз тогда, когда вы к ним целитесь.

### Клавиши

| Клавиша | Действие |
|---|---|
| `F2` | изменить предлагаемое имя выбранной строки |
| `F5` | пересканировать выбранные файлы заново |
| `Пробел` | поставить или снять отметку на выбранных строках |
| `Shift` / `Ctrl` + щелчок | выбрать несколько строк |
| Двойной щелчок по имени | правка предлагаемого имени |
| Кнопка «Перейти к файлу» | открыть папку с файлом в проводнике |
| Правая кнопка мыши | меню действий над строкой |

## 6. Работа шаг за шагом

### 6.1. Выбор папки

Нажмите **«Выбрать»**. Откроется окно выбора папки:

```text
┌ Выберите папку с документами ───────────────────────────────────────────┐
│ Слева — папки, справа — что в выбранной лежит.                          │
│ Двойной щелчок по папке справа открывает её.                            │
│ Папка: [ D:\Дело Петрова                            ]        [ Вверх ]  │
│ ┌ папки ───────────┬ Содержимое ─────────────┬ Размер ┬ Изменён ──────┐ │
│ │ 📁 Диск D:       │ 📁 Сканы                │        │ 18.08.2026    │ │
│ │  ▾ 📁 Дело Пет…  │ 📁 Том 2                │        │ 18.08.2026    │ │
│ │     📁 Сканы     │ Договор займа №17.docx  │  24 КБ │ 18.08.2026    │ │
│ │     📁 Том 2     │ иск.pdf                 │ 180 КБ │ 17.08.2026    │ │
│ └──────────────────┴─────────────────────────┴────────┴───────────────┘ │
│ В папке: 2 папки, 2 файла              [ Отмена ] [ Выбрать эту папку ] │
└─────────────────────────────────────────────────────────────────────────┘
```

Окно своё, а не системное, по одной причине: системное показывает только
названия папок. А папку выбирают не по названию — «Новая папка (2)» и «Скан»
ничего не говорят, пока не видно, что внутри. Здесь содержимое видно сразу:
имена, размеры и время изменения.

- слева — дерево папок, оно раскрывается до открытой папки;
- справа — что в ней лежит; двойной щелчок по папке входит в неё;
- **«Вверх»** поднимает на уровень выше;
- путь можно вписать или вставить в строку «Папка» и нажать `Enter`;
- внизу написано, сколько всего в папке файлов и папок;
- **«Выбрать эту папку»** берёт в работу ту папку, что открыта.

Окно ничего не меняет на диске: файлы только перечисляются.

### 6.2. Сканирование

**«Сканировать»** — программа обходит папку и показывает найденные файлы: имя,
размер, состояние «Найден». Содержимое ещё не читается, это быстрый шаг.
Флажок «Включая подпапки» решает, обходить ли вложенные папки.

Не обходятся: собственные папки программы (`logs`, `manifests`,
`runtime_temp`), системные каталоги, `.git`, `node_modules`, `$RECYCLE.BIN`,
временные файлы Office (`~$…`). Ссылки и junction-точки не выводят обход за
пределы выбранного дерева.

### 6.3. Предпросмотр

**«Предпросмотр»** — главный шаг. Программа читает каждый файл, извлекает
факты и строит имя. Ничего на диске при этом не меняется.

Порядок работы — от дешёвого к дорогому: сначала метаданные и правила, потом
чтение документа, потом распознавание скана, и только в последнюю очередь
локальная модель. Если имя уверенно собирается без модели, она не
запускается вовсе.

### 6.4. Проверка предложений

Пройдите по списку. На каждой строке видно старое имя, предлагаемое,
уверенность и состояние. Щёлкните строку — справа появятся предпросмотр файла
и сведения о том, откуда что взято («Вид: Исковое заявление (из текста)»).

Снимите галочки с того, что переименовывать не надо. Галочка на папке снимает
или ставит отметку сразу на всём её содержимом.

### 6.5. Переименование

**«Переименовать»** спросит подтверждение и покажет, сколько файлов будет
затронуто. Дальше каждый файл проходит одну и ту же проверку:

1. файл на месте и не изменился с момента предпросмотра;
2. целевое имя свободно;
3. считается SHA-256 до операции;
4. выполняется переименование в той же папке;
5. считается SHA-256 после;
6. суммы сверяются;
7. запись добавляется в manifest.

Если файл изменился после предпросмотра, он пропускается с пометкой
`SOURCE_CHANGED_AFTER_PREVIEW` — программа не переименовывает то, чего она уже
не видела. Одна ошибка не останавливает работу с остальными файлами.

Сначала переименовываются файлы, потом папки — от самых глубоких к верхним,
чтобы пути не рассыпались на середине.

### 6.6. Проверка результата

После операции список очищается: имена на диске уже другие, и показывать
старый план было бы враньём. Нажмите «Предпросмотр» ещё раз, чтобы увидеть
папку заново.

Что осталось от операции: журнал в `logs\` и manifest в `manifests\`. По
manifest выполняется отмена.

## 7. Как читать список

Колонки: **Файл или папка**, **✓** (отметка), **Предлагаемое имя**,
**Уверенность**, **Состояние**.

Цвет строки: зелёный — имя готово, жёлтый — нужна ваша проверка, красный —
файл не прочитан.

Частые состояния:

| Состояние | Что значит | Что делать |
|---|---|---|
| Имя готово | всё найдено, уверенность выше порога | ничего |
| `SKIPPED_LOW_CONFIDENCE` | имя предложено, но уверенности мало | посмотреть предпросмотр и решить самому |
| `GOOD_NAME_KEPT` | имя уже хорошее, вариант предложен для сравнения | отметить, если вариант нравится больше |
| `ORIGINAL_NAME_PRESERVED` | осмысленное имя сохранено, добавлена только дата | ничего |
| `TECHNICAL_FILE` | служебный файл (`desktop.ini`, ярлык, база) | ничего, программа его не трогает |
| `ALREADY_RENAMED` | файл уже переименован этой программой раньше | ничего; флажок «Только новые» уберёт такие из списка |
| `NAME_REVIEW_FAILED` | имя не прошло самопроверку и не предлагается | задать имя руками (`F2`) |
| `NO_NAME_PROPOSED` | фактов не хватило | установить распознавание сканов или задать имя руками |
| `OCR_ENGINE_NOT_FOUND` | скан не распознан: нет Tesseract | поставить распознавание, затем `F5` |
| `MODEL_NOT_FOUND` | нет локальной модели, работают только правила | обычно ничего |
| `PASSWORD_PROTECTED` | файл под паролем | снять пароль или переименовать руками |
| `SOURCE_CHANGED_AFTER_PREVIEW` | файл изменился после предпросмотра | повторить предпросмотр |
| `EXTENSION_MISMATCH` | расширение не совпадает с содержимым | проверить файл; расширение программа не меняет |
| `SIDECAR_DETECTED` | рядом лежит связанный файл (`.AAE`, `.XMP`, `.THM`) | переименовать пару вручную |
| `DATE_SOURCE_FILE_PROPERTY` | дата взята из свойств файла, а не из текста | проверить, та ли это дата |
| `NAME_COLLISION_RESOLVED` | имя было занято, добавлен номер | ничего |

Полный список кодов — в [документации для разработчика](РАЗРАБОТЧИКУ.md#12-коды-состояния).

## 8. Когда программа ошиблась

Решение человека важнее любой догадки программы. Всё правится прямо в окне.

**Изменить имя.** Кнопка «Изменить имя» в ряду, двойной щелчок по
предлагаемому имени, клавиша `F2` или правая кнопка мыши → «Изменить имя…». Введённое имя проходит те же проверки:
запрещённые символы, длина, расширение, занятость имени.

**Считать страницами одного документа.** Отметьте файлы и нажмите
**«Объединить»** (или правая кнопка → «Считать одним документом…»). Откроется
окно посреди программы: список редактируемый, щелчок отмечает и снимает
строку, «Добавить файлы…» подтягивает страницу, не попавшую в разбор,
«Убрать из списка» убирает лишнее. Там же задаётся общее имя. Страницы
получат номера по порядку прежней нумерации. Страницы одного документа должны
лежать в одной папке.

**Разобрать заново.** Клавиша `F5` или правая кнопка → «Пересканировать».
Нужно после того, как вы поставили распознавание сканов или локальную модель:
файл разберётся с новыми возможностями.

**Исключить из работы.** Снимите галочку. Отметку можно ставить пробелом
сразу на нескольких выделенных строках.

**Понизить или поднять требовательность.** «Ещё» → «Настройки» → порог
уверенности. Ниже порога программа предлагает имя, но не переименовывает
автоматически.

## 9. Как строятся имена

Общий вид:

```text
Вид_Участники_Номер_Дата.расширение

Постановление_СПИ_Иванов_652102_26_77028-ИП_27.07.2026.pdf
```

Первым идёт вид документа, дата — в конце: так однотипные документы
оказываются рядом при сортировке по имени. Хронологический порядок
включается настройками `naming.order` и `naming.date_format`.

Разделитель частей — одинарное подчёркивание, и только он. Дефис остаётся
лишь там, где он часть самого значения: «пристав-исполнитель», «Бета-Инвест»,
«652102_26_77028-ИП».

Если вид документа определить не удалось, имя начинается с нейтрального
обозначения по формату файла — «Документ», «Таблица», «Презентация», «Фото».

### Осмысленные имена не ломаются

Если файл уже назван по-человечески, имя не переписывается. Максимум —
добавляется дата в начале по единому образцу, и только если её в имени ещё
нет:

```text
Постановление по делу Иванова.pdf → Постановление по делу Иванова_27.07.2026.pdf
Договор займа №17 от 18 августа 2026 года.docx → не трогаем
scan0007.pdf → Договор_Петров_ООО_Альфа_17_18.08.2026.pdf
```

Техническими считаются имена вида `IMG_0032`, `scan0007`, `20260818_142203`,
`Новый документ` — они заменяются полностью. Отключается настройкой
`naming.preserve_good_names`.

### Тома и части

Файлы, отличающиеся только номером, — части одного документа. Номер части
сохраняется, в одно имя они не сливаются:

```text
scan_1.pdf, scan_2.pdf, scan_3.pdf
  → Постановление_СПИ_Иванов_1_из_3_27.07.2026.pdf (и 2_из_3, 3_из_3)
```

Если во втором томе нет шапки с датой или номером дела, они берутся из
соседнего тома — в журнале и manifest указано, из какого именно файла.

### Страницы одного документа

Пачка подряд отснятых или отсканированных страниц — это один документ.
Имя у неё одно на всех, взятое с той страницы, где реквизиты пропечатались, и
различается только номером:

```text
1.pdf … 8.pdf → Иск_ШахмановаМП_ООО_Альфа_2-1183_2026_стр_1 … стр_8
```

Номер дополняется нулями до ширины последнего, поэтому сортировка по имени
совпадает с порядком страниц. Без распознавания сканов имя берётся с папки.
Слова «том» и «часть» понимаются буквально: это части разных документов.

### Фотографии и снимки документов

Обычная фотография называется по метаданным съёмки — программа не выдумывает
сюжет:

```text
IMG_7834.HEIC → Фото_iPhone_16_Pro_03.08.2026_18.42.17.heic
```

Снимок документа — по самому документу, владелец берётся из распознанного
текста:

```text
IMG_5608.jpg → Паспорт_ИвановИИ_фото_03.08.2026.jpg
```

Координаты в имя не добавляются, пока это не разрешено настройкой
`media.include_gps_coordinates`. Обратное геокодирование не выполняется.

### Таблицы, архивы, папки

Таблица называется по ярлычку листа, а дат в ней десятки — поэтому в имя идёт
период: `Реестр_платежей_ООО_Альфа_2025-2026.xlsx`.

Архив, названный человеком, не ломается — лишь дополняется:
`иск Шахманова.zip → Иск_Шахманова_архив_сканы.zip`. Архивы не
распаковываются, читается только список содержимого.

Папка получает имя от того, что в ней лежит: преобладающий вид документов,
общий участник, номер дела и период. Если общего нет вовсе — папка остаётся
как есть. Порог для папок ниже, чем для файлов
(`naming.folder_confidence_threshold`).

### Один человек — одно упоминание

В документе человека называют во всех падежах сразу: «в отношении должника
Иванова», «направить должнику Иванову», «подписано Ивановым». Это один
человек, и в имя файла он попадает один раз. Из найденных в документе форм
выбирается та, какой человека называют, — именительный падеж; придумывать
форму, которой в документе не было, программа не станет. Однофамильцы
остаются разными людьми: в сравнение входят и инициалы, поэтому «Иванов И.И.»
и «Иванова М.П.» в имени уживаются.

### Откуда берётся дата

Порядок: дата рядом с заголовком → дата рядом с номером документа → дата в
верхней части первой страницы → для фото и видео дата съёмки из метаданных.
Дата из свойств файла — только в крайнем случае и с пометкой
`DATE_SOURCE_FILE_PROPERTY`: время изменения файла не является датой
документа. Отключается настройкой `naming.allow_filesystem_date_fallback`.

### Почему имя может не быть предложено

Каждое значение, попадающее в имя, обязано иметь подтверждение в файле:
фрагмент текста, поле метаданных или совпадение по правилу. Значение без
подтверждения отбрасывается, даже если его предложила локальная модель.
Готовое имя ещё раз перечитывается независимой проверкой — она ловит две
даты, повтор слова, случайное число, принятое за номер. При серьёзном
замечании имя не предлагается вовсе: лучше оставить как есть, чем назвать
неверно.

## 10. Отмена

Каждое применение записывает manifest в `manifests\`. Отменить можно:

- кнопкой **«Отменить»** в окне программы — она предложит выбрать manifest;
- командой `DocRenamer.exe --undo ".\manifests\rename_manifest_2026-08-18_142203.json"`.

Перед возвратом каждого имени проверяется, что файл на месте, содержимое не
изменилось (сверяется SHA-256) и старое имя свободно. Если имя занято, файл
пропускается с пометкой `UNDO_TARGET_EXISTS` — ничего не перезаписывается.
Папки откатываются в обратном порядке, от верхних к глубоким. Отмена тоже
пишет свой журнал.

## 11. Очистка метаданных

Правая кнопка мыши на строке → **«Очистить метаданные…»**, в командной
строке — `--scrub`.

| Формат | Что снимается |
|---|---|
| JPEG | EXIF, GPS, модель камеры, миниатюра, IPTC, XMP, профиль ICC |
| PNG | текстовые подписи, время изменения, EXIF |
| PDF | автор, программа, даты, XMP |
| DOCX, XLSX, PPTX | автор, кем изменён, организация, время правки, число редакций, отметки времени внутри архива |

JPEG не пережимается: сжатые данные переписываются байт в байт, качество
снимка не меняется.

**Чего очистка не делает.** Не трогает содержимое: подпись и фамилия,
набранные внутри документа, остаются. Не убирает исправления и примечания
Word — это тоже содержимое. И не отменяет того, что копия файла могла
остаться в другом месте.

По умолчанию очищенные копии складываются в подпапку **«Без метаданных»**, а
исходные файлы не трогаются. Замена исходных подтверждается отдельно: вернуть
удалённые метаданные нельзя, отмены у этой операции нет. Каждая очистка
записывается в отчёт `logs\scrub-*.json` — что удалено и что осталось.

## 12. Большие папки и повторные запуски

На папке в несколько тысяч файлов видно, что работа идёт: внизу окна пишется
этап и остаток, полоса под заголовком показывает долю сделанного, список
наполняется частями. Журнал в окне не растёт без предела — полная запись
ведётся в файл.

Программа помнит, что уже переименовывала: в manifest каждой операции записаны
новое имя и контрольная сумма. Такие файлы получают состояние
`ALREADY_RENAMED`, по умолчанию не отмечаются, а флажок **«Только новые»**
убирает их из списка совсем. Настройка `naming.skip_already_renamed` делает
это поведение постоянным.

Кнопка **«Стоп»** прекращает запуск новых задач. Уже выполненные
переименования не откатываются автоматически — для этого есть отмена.

Если программа была прервана на середине применения, при следующем запуске
она предложит открыть журнал, продолжить анализ или откатить сделанное.

## 13. Настройки

Окно: **«Ещё» → «Настройки»**. Там же — путь к модели и языки распознавания.

| В окне | Что делает |

| Включая подпапки | обходить вложенные папки |
| Использовать локальную модель | разрешать модели разрешать неоднозначности |
| Распознавать сканы | использовать OCR |
| Читать метаданные фотографий | EXIF |

## 14. Командная строка

```bat
DocRenamer.exe                              графический интерфейс
DocRenamer.exe "D:\Документы"               предпросмотр
DocRenamer.exe "D:\Документы" --apply       переименовать
DocRenamer.exe --here --recursive           текущая папка с подпапками
DocRenamer.exe "D:\Документы" --no-recursive  только верхний уровень
DocRenamer.exe "D:\Документы" --forensic    только отчёты, без изменений
DocRenamer.exe --undo ".\manifests\rename_manifest_2026-08-18_142203.json"
DocRenamer.exe "D:\Документы" --save-plan plan.json   сохранить план
DocRenamer.exe --no-ai --no-ocr             без модели и без распознавания
DocRenamer.exe --config ".\config\config.json"   другой файл настроек
DocRenamer.exe --selftest                   проверить готовность комплекта
DocRenamer.exe --wizard                     пошаговый диалог в окне консоли
DocRenamer.exe "D:\Документы" --scrub       снять метаданные (копии в подпапку)
DocRenamer.exe "D:\Документы" --scrub --scrub-replace   заменить исходные файлы
DocRenamer.exe --verbose                    подробный вывод
DocRenamer.exe --version                    версия программы
```

По умолчанию выполняется предпросмотр: команда без `--apply` ничего не меняет.

## 15. Журналы и отчёты

| Где | Что |
|---|---|
| `logs\rename_log_ГГГГ-ММ-ДД_ЧЧММСС.txt` | журнал запуска: что прочитано, что предложено, контрольные суммы |
| `manifests\rename_manifest_ГГГГ-ММ-ДД_ЧЧММСС.json` | запись операции, по ней работает отмена |
| `logs\scrub-*.json` | отчёт об очистке метаданных |
| `logs\learning_report.json` | обезличенный отчёт об именах |

Всё пишется в UTF-8 и открывается как читаемый русский текст. Manifest хранит
кириллицу как есть, без `\u0418\u0432…`.

**Отчёт об именах** («Ещё» → «Отчёт об именах») показывает статистику работы
алгоритма: сколько файлов какого вида разобрано, где не хватило уверенности,
какие имена пришлось править руками. Ни имён файлов, ни фамилий, ни названий
организаций, ни текста документов в нём нет — отчёт показывается целиком до
отправки. Ничего не уходит само: страницу открывает отдельная программа
обновления и только по нажатию кнопки. Отключается настройкой
`learning.enabled`.

## 16. Обновления

«Ещё» → «Проверить обновления». Программа сообщит, если вышла новая версия, и
по вашему согласию скачает и установит её.

Само обновление выполняет **отдельная программа** `DocRenamerUpdate.exe`. Так
сделано намеренно: приложение, которое читает ваши документы, не содержит
сетевого кода вообще, и это проверяется при каждой сборке. Программа
обновления знает про сеть, но никогда не открывает ваши файлы: она скачивает
установщик, сверяет его контрольную сумму по опубликованному списку и
запускает. Файл с несовпавшей суммой удаляется.

Проверка запускается только по нажатию кнопки. Автоматическую проверку при
запуске можно включить в `config.json` (`update.check_on_start`).

## 17. Если что-то пошло не так

| Что видно | Почему | Что делать |
|---|---|---|
| Сканы не распознаются, имена пустые | не установлен Tesseract | положить его в `runtime\tesseract\`, затем `F5` на файлах |
| «Локальная модель не найдена» | нет файла `models\document-model.gguf` | работать по правилам или положить модель |
| Список пуст после сканирования | включён флажок «Только новые», а все файлы уже переименованы | снять флажок |
| Не видно файлов из вложенных папок | снят флажок «Включая подпапки» | поставить его и сканировать заново |
| Файл в списке жёлтый, без отметки | служебный файл или мало уверенности | посмотреть колонку «Состояние» |
| Имя не предложено | не хватило подтверждённых фактов | задать имя руками (`F2`) |
| «Файл занят другим процессом» | документ открыт в Word или Excel | закрыть его и повторить предпросмотр |
| «Слишком длинный путь» | ограничение Windows | сократить путь или включить длинные пути в системе |
| Окно выбора папки не показывает диск | диск недоступен или отключён | вписать путь руками в строку «Папка» |
| Программа не пишет журналы | она запущена из «Загрузок» или из папки без прав | положить её в свою папку |
| Всё идёт медленно на большой папке | тысячи файлов, идёт распознавание | смотреть строку хода работы; «Стоп» прекращает запуск новых задач |

## 18. Ограничения

Честный список того, чего программа не умеет:

- `.doc` и `.ppt` (старый Office) — полный текст не извлекается, доступны
  только свойства документа;
- Camera RAW — только метаданные;
- архивы — только список содержимого, без распаковки;
- пары `IMG_1234.HEIC` + `IMG_1234.AAE` и Live Photo помечаются для ручной
  проверки: групповое переименование в первой версии не выполняется;
- расшифровка речи, распознавание рукописей, определение города по
  координатам, поиск и общий индекс документов — не в этой версии;
- расширение файла программа не меняет никогда, даже если оно не совпадает с
  содержимым: об этом она только предупреждает.

При выборе между «сделать имя красивее» и «гарантированно не ошибиться»
программа всегда выбирает второе.
